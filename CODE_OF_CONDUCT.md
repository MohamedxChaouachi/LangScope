# Code of Conduct

LangScope adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space (issues, pull requests, discussions and reviews) and when someone represents the project elsewhere.

## In short

- Be respectful and welcoming, whatever someone's experience, background or identity.
- Give and accept constructive feedback, and focus on what is best for the project and its users.
- Harassment, insults, personal or political attacks, sexualized language or imagery, and publishing someone's private information without their permission are not acceptable.

The full text of the Contributor Covenant 2.1 at the link above is what applies; this summary does not replace it.

## Reporting

If you experience or see behaviour that breaks this code of conduct, report it to the maintainer, Chaouachi Mohamed (`MohamedxChaouachi` on GitHub), using GitHub's **Report content** option on the comment, issue or pull request. Reports are handled privately, and the person reporting is protected from retaliation.

## Enforcement

The maintainer reviews every report and decides on a response in line with the Contributor Covenant's enforcement guidelines: a private warning, a public warning, a temporary ban, or a permanent ban from the project's spaces, depending on how serious and how repeated the behaviour is. The maintainer may also remove, edit or reject comments, commits, code, issues and other contributions that break this code of conduct.
